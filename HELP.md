# Editor Command Reference
- `P` : Prints document with line numbers.
- `I <line> <text>` : Inserts `<text>` at position `<line>`.
- `D <line>` : Deletes the line at position `<line>`.
- `Q` : Quits the editor.

P                  → Display document
I <line> <text>    → Insert a line
D <line>           → Delete a line
S <filename>       → Save file
L <filename>       → Load file
F <word/phrase>    → Search
R <word> <new>     → Find & replace
U                  → Undo last action
