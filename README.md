## Features Implemented
We implemented the following core features:
1. **Insert a line:** Adds a new line of text at a given line number.
2. **Delete a line:** Removes the line at a given number.
3. **Display the document:** Prints all current lines with their line numbers.

## How to Compile and Run
To compile the editor using GCC, run this command in your terminal:
`gcc -Wall -Wextra editor.c -o editor`

To run the compiled editor on Windows, use:
`.\editor`
